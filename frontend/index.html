    Data & backups

    Portable archives with dependency checks

    Carry one asset, a linked bundle, or the whole scriptorium to another installation.

    Exports are reviewed before download. Imports are staged and collision-checked before anything local changes; no AI calls or provider charges are involved.

    Audio is always optional. Your login and browser sessions never enter an archive; portable archives are not encrypted.

    Security

    Password and local sessions

    Change the password for this installation. This immediately locks every other browser session.

    Use at least 15 characters. Spaces and Unicode are welcome; arbitrary symbol rules and forced expiry are not.

    Forgotten password? Stop the server and run cd backend && npm run auth:reset -- --yes. Manuscripts and assets are preserved.
