# Historical planning sources

These four documents are retained to make the reasoning and specialist review reproducible. They are superseded by [implementation guide 1.1](../IMPLEMENTATION-GUIDE.md) and [continuation state](../CONTINUATION.md).

The original draft texts are preserved except for portable relative links. Project notes and proposal links were converted from session-local paths so they work from the repository. Local line numbers were removed because they are snapshot references, not maintained source anchors. Any statement that files were uncommitted or no publication occurred describes the original investigation/review stage, before the later stakeholder request to publish everything on main.
