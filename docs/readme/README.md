# GitHub front-page image

`desk-desktop.png` shows the current InkMorrow Desk at 1440 × 1080, captured
on 2 November 2026 from application 5.0.0/schema 29 at `1715ad6`.

The built-in Drowned Bell opening was created through the authenticated current
fiction API in a disposable in-memory application instance. No owner data,
credentials, generated passages or paid calls were used. Outbound requests were
blocked; the capture completed with zero server outbound attempts. The instance
and its private media directory were disposed after capture.

The image is a product overview for the repository README. It is separate from
the screenshots used by the PDF manuals and is not evidence of live model quality,
real Android acceptance or deployment.
